What Is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

HTML Tags

  1. <html> - Defines the HTML document.
  2. <head> - Contains page information.
  3. <title> - Sets the page title.
  4. <body> - Contains visible content.
  5. <h1> - Creates a main heading.
  6. <h2> - Creates a second-level heading.
  7. <p> - Creates a paragraph.
  8. <br> - Adds a line break.
  9. <hr> - Adds a horizontal line.
  10. <a> - Creates a link.
  11. <img> - Displays an image.
  12. <ul> - Creates an unordered list.
  13. <ol> - Creates an ordered list.
  14. <li> - Defines a list item.
  15. <div> - Groups content.
  16. <span> - Groups inline content.
  17. <strong> - Marks important text.
  18. <em> - Emphasizes text.
  19. <button> - Creates a button.
  20. <input> - Creates an input field.
  21. <form> - Creates a form.
  22. <label> - Labels a form field.
  23. <table> - Creates a table.
  24. <tr> - Creates a table row.
  25. <th> - Creates a table heading cell.
  26. <td> - Creates a table data cell.
