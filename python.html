Python Types and Variables

Learning the basics of Python programming

What are Variables?

Variables are used to store information. A variable can hold numbers, text, or other data. 

name = "Jonatan"
age = 17
print(name)
print(age)

Python Data Types

String (str): Stores text.

name = "Jonatan"

Integer (int): Stores whole numbers.

age = 17

Float: Stores decimal numbers.

height = 5.8

Boolean (bool): Stores True or False.

is_student = True

Example Program

name = "Jonatan"
age = 19
is_student = True

print("My name is", name)
print("I am", age, "years old")
print(is_student)

This program uses variables to display information about a student.

What I Learned

I learned how to create variables and use different data types in Python. Variables help organize and store information.
